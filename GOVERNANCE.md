# Governance Model (Non-Investment / Non-Financial)

## What token votes CAN control (safe)
- Content themes and community events
- Study guide and printable priorities
- Community roles / badges / recognition
- Which free resources get built next
- Community standards and moderation policies (non-financial)

## What token votes MUST NOT control (risky)
- Allocations promising profit (“deploy treasury for yield”)
- Buybacks / liquidity support / market-making
- Revenue distribution, dividends, or “holder rewards”
- Any policy that implies holders benefit financially from others’ efforts

## Proposal types (recommended)
- **Resource Proposal:** create a free study guide, printable, checklist, or reading plan
- **Event Proposal:** schedule a livestream, Q&A, community reading
- **Recognition Proposal:** badges/roles, contributor acknowledgments
- **Operations Proposal:** improve repo structure, documentation, moderation processes

## Decision rule (simple)
- Proposals must be **non-financial in benefit** and **non-investment in marketing**
- If a proposal sounds like it increases token value, it is rejected

## Transparency
All proposals, discussions, and decisions should be recorded in public (Issues/Discussions).
