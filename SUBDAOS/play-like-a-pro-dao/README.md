# Play Like a Pro DAO — Community Support Token (PLP CST)

**Community Support Token:** a meme/fan token for cultural participation and transparent community coordination around the Play Like a Pro ecosystem. **No ownership. No profit rights. No promised returns.**

This SubDAO inherits all compliance and marketing rules from the parent GCB DAO CST repository.

Primary focus:
- Free training resources, drills, checklists
- Community events and recognition
- Non-financial votes on what gets built next
