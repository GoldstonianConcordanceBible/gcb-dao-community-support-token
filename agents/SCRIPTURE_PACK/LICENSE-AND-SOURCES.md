# Scripture Pack — License & Sources

This pack is intended to use **public-domain Bible texts** by default.

Recommended public-domain options:
- King James Version (KJV) — public domain in the U.S.
- World English Bible (WEB) — public domain

IMPORTANT:
- Many modern translations are copyrighted. Do not include them without permission.
- Keep verse citations (Book chapter:verse) in outputs.
- If you quote, keep excerpts short and attributed.
