# Divine Intelligent Agent Swarms (GCB)

This directory contains forkable agent templates (“swarms”) for the
**Goldstonian Concordance Bible (GCB)** ecosystem.

These swarms are designed for:
- Scripture-aware reasoning (retrieval-first, citation-required)
- Concordance-style cross-referencing
- Doctrine-guided outputs (“Mirror → Water → Fire” decision logic)
- Builder mode (Web3 governance + open-source workflows)

## Important
- This repo provides **RAG packs**, prompts, and structure.
- It does **not** require (or recommend) training a model on scripture text.
- If you fork, keep attribution per WEB3/FORK-ATTRIBUTION.md
